# 多元假设检验：特征扩展
**[English](./03_multivariate_analysis.md) | 中文**

*(改编自论文第 4 章)*

## 1. 为什么需要多元分析？
在教育评估中，期末成绩、出勤率和学习时长等变量是高度相关的。独立地检验它们（单变量）可能会夸大第一类错误，并错失联合效应。因此，我们将因变量扩展为**三维向量**（成绩、出勤率、学习时长），并将分析拓展至多元方差分析（MANOVA）。

## 2. 方法与前提条件
- **博克斯 M 检验**：检查各组间协方差矩阵的齐性。
  *结果：* M = 28.332, p = 0.555。满足协方差齐性假设。
- **霍特林 T² 检验**：比较两组之间的均值向量（课外活动：是 vs. 否）。
- **威尔克斯 Λ 检验**：比较多组之间的均值向量（父母参与度：低、中、高）。

## 3. 关键发现与多元洞察

### 霍特林 T² 检验（课外活动）
- **结果**：F(3, 6599) = 1.210, p = 0.304。
- **洞察**：多元主效应**不显著**。
- **与第 3 章的对比**：单变量 t 检验显示了显著差异（p=0.016）。然而，当我们联合考虑出勤率和学习时长时，考试成绩的微小差异被多维空间的背景噪音所吸收。

### 威尔克斯 Λ 检验（父母参与度）
- **结果**：F(6, 13198) = 0.413, p = 0.871。
- **洞察**：无显著主效应。
- **交互效应**：有趣的是，交互项（课外活动 × 父母参与度）呈现边缘显著趋势（p = 0.054）。这表明存在潜在的协同机制，只是当前的统计功效无法完全证实。

## 4. 结论：联合推断的力量
第 3 章与第 4 章之间的对比揭示了一个深刻的统计原则：**单一指标的显著性可能具有欺骗性。**

在处理高维数据时，孤立地评估变量通常会导致假阳性（类似于机器学习中的过拟合）。通过从边缘分布转向联合分布（MANOVA），我们成功降低了因维度叠加导致假阳性膨胀的风险。这种多元视角——从多个特征的交互中学习，而非孤立地看待单一列，正是我渴望在人工智能和机器学习领域深造的原因。
