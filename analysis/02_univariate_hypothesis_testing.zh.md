# 教育评估中的单变量假设检验
**[English](./02_univariate_hypothesis_testing.md) | 中文**

*(改编自论文第 3 章)*

**数据集：** [Student Performance Factors (Kaggle)](https://www.kaggle.com/datasets/lainguyn123/student-performance-factors) 
**样本量：** N = 6,607

## 1. 探索性数据分析（EDA）与前提假设检验
在进行参数检验之前，我们进行了严格的前提假设检查：
- **正态性**：通过带正态曲线的直方图和 Q-Q 图进行可视化。尽管 Kolmogorov-Smirnov 检验拒绝了某些子组的严格正态性，但大样本量（N = 6,607）确保了中心极限定理（CLT）成立，使得 t 检验具有稳健性。
- **方差齐性**：Levene 检验揭示了课外活动组之间存在轻微的方差不齐（p=0.028）。然而，考虑到大样本量以及几乎相同的标准差（比值约为 1.03），标准 t 检验的结果被认为是可靠的。
- **异常值**：在确认“学习时长”和“期末考试成绩”中的离群点代表了真实的行为差异而非数据录入错误后，我们予以保留。

## 2. 检验选择与实证结果
我们进行了三项单变量检验以调查不同的因素。

### 案例 A：卡方检验（网络接入与及格率）
- **结果**：χ² = 1.054, df = 1, p = 0.305。
- **解读**：无显著关联。拥有网络接入并不能独立决定考试是否及格，这可能是由于在现代教育中网络接入的“门槛效应”正在减弱。

### 案例 B：独立样本 t 检验（课外活动与成绩）
- **结果**：t = 2.402, df = 6605, p = 0.016。
- **解读**：具有统计学显著性。参加课外活动的学生得分略高（均值差 = 0.5277）。

### 案例 C：单因素方差分析（父母参与度与成绩）
- **结果**：F(2, 6604) = 0.420, p = 0.657。
- **解读**：低/中/高各组之间无显著的整体差异。

## 3. 深度反思：p 值陷阱（统计显著 vs. 实际显著）
本章中最有价值的教训来自于**案例 B**。
虽然 p 值（0.016）越过了显著性阈值，但在 100 分制的考试中，实际的平均分差异仅为 **0.5277 分**，且两组的分布几乎完全重叠（见 `figures/03_score_by_extracurricular_boxplot.png`）。

**对 AI/DS 的核心启示：** 
在海量样本量（N = 6,607）下，p 值很容易检测到微小且实际毫无意义的差异。在数据科学中，盲目相信统计显著性而不检查效应量是危险的。这段经历教会了我结合实际情境评估指标——这种思维方式直接适用于评估机器学习模型，因为一个统计上显著的特征可能根本没有任何实际的预测能力。
